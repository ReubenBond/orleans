# The simulation kernel's banned APIs, which replace Orleans' runtime list (src/BannedSymbols.txt) for this project.
#
# The kernel implements controlled waits in virtual time. Its Task.Wait, WaitAll, and WaitAny shims complete a wait
# through the controlled scheduler, then call the BCL's (Task[], int, CancellationToken) and (int, CancellationToken)
# overloads with a zero timeout, which never block, to reproduce the BCL's exact result and exception semantics. Those
# three overloads are therefore permitted here; every other blocking overload remains banned.

# Blocking task APIs block a real thread outside the controlled scheduler.
M:System.Threading.Tasks.Task.Wait;Await the task, or complete the wait through the controlled scheduler.
